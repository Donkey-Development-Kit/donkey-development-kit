# Discovery

Discovery reads the Exchange catalog and the gateway instances in front of it.
What you get back depends on the surface, because the three surfaces are found
in different ways.

| Surface | You ask for | You get | Page |
| --- | --- | --- | --- |
| **Models** | A model id you already know | A `ModelHandle` from `donkey.llm.resolve()`. The proxy has no catalog endpoint to list. | [Models](/registry/discovery/models) |
| **MCP tools** | Governed tools, by governance, tags or name | A `ToolSet` from `donkey.tools.discover()`, or registry handles from `donkey.registry.search()` | [MCP tools](/registry/discovery/mcp) |
| **A2A agents** | One agent by its Exchange reference | An `AgentHandle` with the deployed endpoint, from `donkey.registry.resolve_agent()` | [A2A agents](/registry/discovery/a2a) |
